### 👨‍💻 About Me

I am a **DevOps Engineer and Software Developer** with **6+ years of professional engineering experience** bridging low-level Linux systems administration, cloud infrastructure automation, and modern cross-platform application development.

My foundation began in cybersecurity and systems administration—earning **LPIC-1**, **CompTIA Linux+**, **Network+**, and **SUSE CLA** certifications. Since then, I have delivered production software across healthcare billing systems, fast-paced agency environments, and cloud infrastructure:
- **Cloud & DevOps**: Architecting declarative Google Cloud Platform (GCP) infrastructure using **Terraform**, orchestrating deployments with modular **Ansible** playbooks, enforcing zero-trust container isolation in **Docker**, and managing hardened **Nginx** reverse proxies with automated TLS 1.3 lifecycle management.
- **Cross-Platform Engineering**: Building high-performance mobile, web, and desktop applications primarily with **Flutter/Dart**, paired with robust microservices and APIs in **Go**, **Python**, **PHP (Laravel)**, **Java (Spring Boot)**, and **C#**.
- **Hardened Systems Administration**: Tuning Linux kernels (`sysctl`), configuring proactive intrusion prevention (**Fail2ban** multi-jails), restrictive firewalls (**UFW/iptables** default DENY), and reliable **systemd** service architectures.
